Что такое D4-Site

Два принципа, на которых всё держится

Красота и скорость не должны исключать друг друга.

Гибкая настройка

Цвета, акценты, карточки и пейзажи меняются в один клик. Это не просто тёмный режим, а целый образ, который вы выбираете сами.

Лёгкость

Чистые HTML, CSS и несколько строк скрипта. Страница открывается мгновенно и не нагружает устройство.

Меньше слоёв — больше скорости

Вместо тяжёлых фотографий пейзажи собраны из градиентов и векторных гор. Анимации используют только transform и opacity, а скрипт занимает несколько строк, поэтому страница плавная даже на старых устройствах.

Выберите настроение

Нажмите на любую картинку, и вся страница перекрасится вместе с пейзажем.

Хотите настоящие фото? Положите снимок в папку assets/ и добавьте в CSS для .scene строку background-image:url(assets/photo.jpg);background-size:cover — горы можно убрать, удалив svg внутри.
