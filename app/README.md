# D4 — рабочий стол Windows, собранный под вас

Приложение для кастомизации Windows 10 и 11 на C# + WPF (.NET 8). Первая версия (MVP):

- **Свой бар** вместо панели задач: меню D4, закреплённые программы, открытые окна, часы. Сверху или снизу, высота настраивается. Резервирует место на рабочем столе (AppBar), поэтому окна не залезают под него.
- **Виджеты на рабочем столе:** часы, монитор процессора и памяти, заметки. Перетаскиваются мышью, положение запоминается.
- **Сеть, звук, батарея на баре:** клик по значку сети показывает список Wi-Fi (подключение к сохранённым сетям, отключение; для новых открывается системное окно с вводом пароля), громкость — ползунок, колесо мыши и выключение звука, батарея — заряд и остаток времени.
- **Своё меню «Пуск» с поиском** (кнопка на баре, поле «Поиск» и клавиша Win): закреплённые и все программы, поиск по названию, запуск файлов/путей, поиск в интернете, питание (сон, перезагрузка, выключение). Стрелки + Enter, Esc закрывает.
- **Свой обзор окон** (значок на баре справа): живые миниатюры окон в стиле темы, клик — переход, ✕ — закрыть.
- **Системные окна под тему:** D4 переключает Windows в тёмный/светлый режим и меняет цвет акцента вместе с темой (Параметры, Проводник и др.). При выходе всё возвращается. Отключается галочкой в настройках.
- **Свой логотип «Пуск» для каждой темы** (океан, закат-солнце, лес-клевер, неон со свечением, светлая).
- **5 тем** (Океан, Закат, Лес, Неон, Светлая) и **обои**: пейзаж темы, своя картинка или видео. Обои лежат под иконками рабочего стола, видео ставится на паузу под окнами на весь экран и развёрнутыми окнами.
- **Мини-папки:** перетащите в них файлы и программы, клик запускает. Три формы, двойной щелчок по названию переименовывает.
- Значок в трее, автозапуск с Windows, настройки в `%AppData%\D4\settings.json`.

## Сборка и запуск

Нужны Windows 10/11 и [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```powershell
cd app
dotnet run -c Release
```

Готовый exe одним файлом:

```powershell
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

Результат: `bin\Release\net8.0-windows\win-x64\publish\D4.exe`.

## Как это работает

- **Бар заменяет панель задач.** Панель Windows по умолчанию скрыта (и освобождает место), на баре по центру — док со значками: закреплённые и запущенные приложения. Клик запускает или переключает окно, повторный клик по активному сворачивает его, правый клик — закрепить, открепить, закрыть. Кнопка ⊞ открывает меню «Пуск». Значки растут волной под курсором, под запущенными есть полоска, у активного она длиннее.
- **Обои.** Картинки и пейзаж темы D4 ставит как обычные обои Windows, а при выходе возвращает прежние. Видео играет в окне под иконками рабочего стола.
- **Выбор окон.** Если у приложения несколько окон, клик по значку открывает список: выберите нужное или закройте крестиком. Правый клик по любому значку — список окон и действия (открыть ещё одно, закрепить, открепить, закрыть все).
- **Справа на баре:** ⧉ обзор задач (Win+Tab), ⌃ скрытые значки трея (на 12 секунд показывает панель Windows), значок сети (имя Wi-Fi, сигнал, IP, быстрые параметры Win+A) и часы.
- **Журнал.** `%AppData%\D4\d4.log` — туда пишется, как встроились видео-обои и что пошло не так.

## Важно

- Пока панель Windows скрыта, в ней не видны значки трея (громкость, сеть, часы Windows). Чтобы вернуть её, нажмите на значок D4 в трее → «Скрыть/показать панель задач Windows» или снимите галочку в настройках.

- Панель задач Windows возвращается при любом завершении D4: при выходе, при выходе из системы, после сбоя и даже если закрыть D4 через диспетчер задач (за этим следит крошечный процесс-сторож `D4.exe --watch`). Вернуть её вручную можно командой `D4.exe --restore-taskbar`.
- Видео-обои используют кодеки Windows (MediaElement). Если файл не открылся, показывается пейзаж темы.
- Версия написана без возможности запустить её на Windows, поэтому возможны мелкие ошибки при первой сборке. Присылайте текст ошибки, исправлю.

## Структура

| Файл | Что делает |
|---|---|
| `Program.cs`, `Shell.cs` | запуск, значок в трее, управление всеми окнами |
| `Settings.cs` | настройки и их сохранение |
| `Flyout.cs`, `Network.cs`, `AudioVolume.cs`, `StartLogo.cs` | всплывающие панели, Wi-Fi, громкость, логотип «Пуск» |
| `Launcher.cs`, `TaskView.cs`, `WinKeyHook.cs`, `SystemTheme.cs` | меню «Пуск» с поиском, обзор окон, перехват клавиши Win, тема системных окон |
| `Themes.cs` | палитры тем, смена на лету |
| `Native.cs` | Win32: AppBar, окно под иконками, список окон, нагрузка системы |
| `BarWindow.cs` | бар |
| `WallpaperWindow.cs`, `SceneFactory.cs` | обои и пейзажи тем |
| `Widgets.cs` | основа виджетов, часы, монитор, заметки |
| `MiniFolderWindow.cs` | мини-папки |
| `SettingsWindow.cs` | окно настроек |
